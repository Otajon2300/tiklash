# Tiklash

Windows uchun o'chgan fayllarni tiklash dasturi — **otashDEV** (Otajon Davronov).

- NTFS, FAT, exFAT, ext2/3/4 va HFS+ disklaridagi o'chgan fayllar nomi va papkasi bilan;
- formatlangan yoki shikastlangan disklarda imzo bo'yicha qidiruv (500 dan ortiq fayl turi);
- uzilgan videolarni ta'mirlash (MP4/MOV, AVI, MKV/WebM).

## Yuklab olish

[Relizlar](../../releases) bo'limidan `Tiklash-<versiya>-ornatish.exe` ni yuklab, o'rnating.
O'rnatilgan dastur yangi versiyani shu yerdan o'zi tekshiradi; har bir fayl muallif imzosi (`.sig`) bilan tekshirilib o'rnatiladi.

**Muhim:** o'chgan fayllar turgan diskka dasturni o'rnatmang va tiklangan fayllarni o'sha diskka saqlamang.
